Como funciona

Os dois modos seguem as mesmas etapas e mudam apenas a unidade comparada: palavras ou frases.

  1. Alinhamento: o algoritmo de Hirschberg divide o texto ao meio para achar a maior sequência em comum.
  2. Blocos: as correspondências vizinhas são unidas, então mover um parágrafo conta como um único movimento.
  3. Ordem: um merge sort modificado conta as inversões entre blocos e ignora pequenas trocas locais.
  4. Nota: cobertura × (0,5 + 0,5 × ordem). Citações entre aspas e referências são ignoradas.

O resultado é um indício para revisão humana, não uma prova de plágio.
